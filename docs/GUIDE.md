# 第一部分：这个项目是什么

## 1. 一句话

**我们给大模型出了一张"核聚变物理试卷"，配了一台不掺假的"自动阅卷机"，再造了一条"保证标准答案不出错"的质检流水线，最后把题库、阅卷机、质检日志和一篇 NeurIPS 论文全部开源到 GitHub。**

## 2. 为什么值得做

- 通用科学卷（SciBench/GPQA/奥赛卷）里聚变题≈0，而 GPQA 已被头部模型刷到 92%——社区缺"又难又能客观判分"的新卷子；
- 唯一的聚变题库（北大 FusionBench，10,605 题）我们逐题审计过：**带单位数值的计算题只占 0.75%**，ICF 纵深<5%，且答案无任何独立验证——它考"知不知道"，不考"会不会算"；
- 聚变界现有 AI 活动都是 ML 竞赛（磁平衡重建、诊断预测），不是物理推理评测。

所以我们占住四个空白的交集：**ICF 纵深 × 定量题型 × 答案机械验证 × SWE-bench 式好用**。

## 4. 质检流水线（项目的"护城河"）

题目先进暂存区（staging），闯四关才进正式题库（verified）：

1. **Schema 校验** — 字段完整性、题型与判分方式配套、rubric 权重和=1；
2. **独立复算** — 每道数值题自带一条用第一性原理重推答案的 Python 表达式，脚本在沙箱里重算，偏差必须小于判分容差的一半（当前 **567/567 全过**）；
3. **双方法要求** — 概念/推导题必须注明 ≥2 种独立验证方法（交叉来源/专家复核/第二解法）；
4. **晋级门 + 公开日志** — 每批晋级写进 `docs/verification-log.md`，被拒的题和原因全部留痕。

它真咬过人：**两次我自己的手算错误**（Saha 前置系数指数滑移差 31.6 倍、德拜长度 kT 指数错 1000 倍）都被复算表达式当场抓住修正；**一套电容器预测数据集因自身审计 WARN 被整体拒收**，一颗题都不给出。

## 5. 本地资料的"安检"

- Z 箍缩零维数据 10,944 行 → 逐行验证 E=½mv² 恒等式（10,942 行通过）→ 才允许出 93 道 Z 箍缩题；
- Rosseland 不透明度程序 → 强制单核重跑输出**字节级一致** + 占据分布独立加权求平均电离度与程序输出**零偏差**双互证；
- FLASH 15MA 铝套筒算例 → 输出未复跑 → **只出参数/设置题，不出输出数值题**。

# 第三部分：判分方式详解（数值题完整拆解）

## 3.1 规则（写死在代码里，任何人跑结果相同）

对每道数值题，阅卷机做四件事：

1. **抽取答案数字**：优先找回答里**最后一个** "Final answer:" / "答案:" / "answer:" 标记，取其后的**第一个**数字；找不到标记就取**全文最后一个**数字；
2. **读标准答案**：题目里存着 `value`（标准值）、`tolerance_rel`（相对容差，一般 0.02 即 ±2%）；
3. **比较**：`|抽取值 − 标准值| / |标准值| ≤ tolerance_rel` → 1 分，否则 0 分；
4. **写明细**：每题存 `gold=…, got=…, rel_dev=…, tol=…`，可复核。

## 3.2 真实例题

题目 `icf-ignition-gain-0001`（数值/本科）：

> 2022 年 12 月 5 日 NIF 首次实现点火：激光输入 2.05 MJ，聚变产额 3.15 MJ。靶增益定义为 G = 聚变产额 / 入射激光能量。求 G。

题目里存的标准答案：`value=1.54, tolerance_rel=0.03`；独立复算表达式：`3.15/2.05`（=1.5366，与 1.54 相对偏差 0.2%，远小于容差一半——这就是它进得了正式题库的原因）。

## 3.3 模拟一次阅卷

假设某模型回答：

```
激光能量 2.05 MJ，产额 3.15 MJ。
靶增益 G = 3.15 / 2.05 ≈ 1.5366。
Final answer: 1.54
```

阅卷过程：
- 找到最后一个 "Final answer:" 标记 → 其后第一个数字 = **1.54**；
- 与标准值 1.54 比较：相对偏差 = 0 ≤ 3% → **得 1 分**，明细记录 `gold=1.54 got=1.54 rel_dev=0.00e+00 tol=3.0e-02`。

如果模型答"约 1.5 倍，因为……Final answer: 1.5"：相对偏差 = |1.5−1.54|/1.54 = 2.6% ≤ 3% → **仍得分**（容差就是为合理的舍入留的）。
如果模型把单位换算搞错答 1540：偏差 10 万倍 → **0 分**。

## 3.4 为什么敢说"客观"

- 阅卷是**纯函数**：同样的（回答，题目）永远得出同样的分，零模型调用、零主观判断；
- **烟囱测试**：把 691 题的标准答案本身当"模型回答"喂给阅卷机，678 道确定性题**全部满分**——证明抽取和比较逻辑没有 bug；
- 13 道推导题走 rubric 评审（锁定评审模型与 prompt 版本，每题 4-5 个加权评分点，权重和=1），**单独成行报告，绝不混进确定性总分**。

## 3.5 其他题型一览

| 题型 | 规则 |
|---|---|
| 概念多选 | 抽取回答中的选项字母集合，与答案集合**精确相等**才得分（漏选/错选都不行） |
| 代码题 | 模型代码写入沙箱，跑题目自带的单元测试，全部通过=1 分 |
| 图表题 | 按数值容差判分 |
| 推导题 | rubric 评分点加权求和 ≥ 0.8 通过，单独报告 |
